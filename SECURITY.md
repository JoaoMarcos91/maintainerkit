# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository, or contact the maintainer privately through their GitHub profile.

## Scope and limitations

MaintainerKit is an issue-triage helper, not a security scanner. It does not establish whether a vulnerability report is valid. Keep workflow permissions minimal and never commit API keys or tokens.

When AI mode is enabled, issue content and selected excerpts from other open issues are sent to the configured provider. Only enable this if that data transfer is acceptable for your repository.
