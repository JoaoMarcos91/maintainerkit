# Contributing

Thanks for considering a contribution!

## Before opening a pull request

1. Open an issue for substantial changes so the approach can be discussed.
2. Keep changes focused and explain the user problem they solve.
3. Add or update tests for behavior changes.
4. Run the test suite with `python3 -m unittest discover -v`.
5. Never include API keys, tokens, private issue data, or personal information.

## Development

MaintainerKit uses Python's standard library at runtime. Python 3.10 or newer is recommended for local development.

## Pull requests

Describe the behavior before and after your change, note any limitations, and include test results. MaintainerKit is review-first: avoid introducing automatic destructive actions or changing labels by default.
